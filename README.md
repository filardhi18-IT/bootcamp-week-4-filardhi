# Interactive Profile Card (React Fundamental)

Aplikasi web React sederhana menggunakan Vite untuk menampilkan kartu profil interaktif dengan fitur Like Counter.

## 🚀 Fitur & Pengerjaan
- **Header Component**: Komponen header aplikasi.
- **Card Component**: Komponen kartu profil dinamis menggunakan Props.
- **State (useState)**: Fitur Like counter interaktif pada setiap kartu.
- **Multiple Cards**: Menampilkan beberapa kartu profil berbeda.
